# KenazCoin docs

This folder is the documentation of KenazCoin. It is split by subject so
each doc can be read on its own.

## Index

| Doc | What it covers |
| --- | --- |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | The big picture: modules, the path of a transaction, the path of a block, mining, the network, and what maps to a real blockchain. |
| [`THEORY.md`](THEORY.md) | The ideas behind the code: UTXO, RSA wallets, proof of work, difficulty, halving, merkle trees, persistence, networking. |
| [`USER_GUIDE.md`](USER_GUIDE.md) | How to actually use it: run a node, the commands, demos, troubleshooting. |

## Reading order

If you are new, the short path is:

1. `ARCHITECTURE.md` for the map.
2. `USER_GUIDE.md` to get it running and poke around.
3. `THEORY.md` for the ideas behind the code.

## About this documentation

- Where the code and the text disagree, the code wins and the doc is
  wrong. Sometimes things change without the docs catching up.
