O sistema cria um TxInput apontando 
para uma nota antiga que o Carlos tinha no painel do UTXOSet.

O sistema verifica no UTXOSet se essa nota realmente existe e pertence ao Carlos.

Se sim, o sistema remove essa nota antiga do UTXOSet (ela foi gasta!).

O sistema cria um novo TxOutput onde o address é a Mariana e o amount é 5.

Esse novo TxOutput da Mariana é adicionado ao UTXOSet, ficando lá parado,
esperando o dia em que a Mariana decida gastá-lo

class Espada:
    def __init__(self, nome, dano):
        self.nome = nome
        self.dano = dano

class Guerreiro:
    def __init__(self, nome):
        self.nome = nome
        self.arma = None # Começa sem nada

# 1. Criamos a espada (Classe Espada)
excalibur = Espada("Excalibur", 50)

# 2. Criamos o guerreiro (Classe Guerreiro)
conan = Guerreiro("Conan")

# 3. Colocamos o objeto da espada DENTRO do guerreiro!
conan.arma = excalibur

# 4. Acessando uma classe através da outra:
print(conan.arma.dano)  # Saída: 50


O new_transfer abstrai isso: você passa sender, receiver, 
amount igual antes, e ele automaticamente procura UTXOs do sender, 
monta os inputs, calcula troco, e assina. Então a interface de uso 
continua simples, mas por baixo agora existe a contabilidade real.
