imagine um bloco com 5000 transações 
e o usuário quer apenas uma tx_3841

ao inves de baixar todo o bloco, a merkle tree transforma milhares de
transações em um único hash(resumo) = Markle Root


Cada transação vira um hash:
h = H(tx)
etc...

depois agrupa em pares:
h1,2 = h(h1 + h2)

então:
tx1 h1
tx2 h2
tx3 h3
tx4 h4
então:
h1,2 = H(h1+h2)
h3,4 = H(h3+h4)
então:
root = h(h1,2 + h3,4)

          root
        /      \
      h12      h34
     /  \      /  \
    h1  h2   h3  h4

O bloco não precisa guardar todos os hashes intermediários no header

Ele guarda apenas o merkle_root

qualquer alteração numa transação muda o hash dela, os acima e a root interia

Sem árvore: O(n)
Com Merkle Proof: O(log n)

Se houver n(ímpar) o último é duplicado
