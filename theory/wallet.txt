miller rabbit test

a fast, probabilistic algorithm used to determine whether a given number is 
likely prime

To test an odd integer n > 2, the algorithm follows these steps:

Decompose n - 1: Express n - 1 as (2^S * d), where d is an odd number.

choose a ramdom base a: pick a random integer a such that 2 =< a =< n - 2

calculate x = a^d (mod n)

check base conditions: if x == 1 ir x == n - 1
the number n is "probably prime" for this base. 
You pass the test and move to the next iteration.

[CLASS ARCHITECTURE: Wallet]
- On Instantiation (`__init__`):
  * Generates two independent 512-bit primes ('p' and 'q').
  * Computes public modulus 'n' (1024-bit total) and 'phi'.
  * Fixes public exponent 'e' to the industry standard 65537.
  * Extracts the 'address' from the last 16 hex characters of the public key.
- Sign Method (`sign`):
  * Signs text by calculating: Signature = (Hash(Message) ^ d) % n.
- Verify Method (`verify`):
  * Decrypts signature by calculating: Restored_Hash = (Signature ^ e) % n.
  * Validates identity by ensuring Restored_Hash matches local Message Hash.
