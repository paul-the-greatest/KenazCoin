index = é a posicao na cadeia (um numero inteiro)

Para que serve:
Organizar a sequência lógica
Ajudar na validação
Debug e leitura humana

timestamp = Tempo de criação do bloco

Para que serve:
Ordenação temporal
Ajuste de dificuldade (no Bitcoin)
Limitar manipulações

data = lista d transacoes 

Cada transação contém:
remetente
destinatário
valor
assinatura

Sem transações, o bloco não tem utilidade econômica.

nonce = Um número inteiro que começa em 0. 
serve pra permitir um hash válido 
hash=H(dados+nonce)
Sem o nonce, não existe mineração.

hash = SHA256(SHA256(index+timestamp+data+previous_hash+nonce))

ex: 

Encontrar um hash assim:
0000a7f3b92....

Você pega os dados do bloco:
index
timestamp
transactions
previous_hash
E começa:
nonce = 0 → hash = 8f3a... F
nonce = 1 → hash = 91bc... F
nonce = 2 → hash = 000af... T
